# 📚 Estruturas de Dados — Projetos em C

Este repositório reúne implementações, exercícios e estudos práticos sobre **Estruturas de Dados**, desenvolvidos em **linguagem C**, com foco em compreensão teórica, eficiência algorítmica e implementação manual de estruturas fundamentais.

Os projetos foram realizados no contexto da disciplina **Estruturas de Dados** do **Departamento de Computação — UFS**, servindo tanto como material de estudo quanto como base para avaliações e experimentações.

---

## 🧠 Conteúdos Abordados

O repositório contempla os principais tópicos clássicos de Estruturas de Dados, incluindo:

### 🔹 Fundamentos
- Ponteiros e manipulação de memória
- Análise de complexidade (tempo e espaço)
- Relações de recorrência

### 🔹 Estruturas Lineares
- Listas (simples, duplas, circulares)
- Pilhas (LIFO)
- Filas (FIFO)
- Filas de prioridade

### 🔹 Busca e Organização
- Busca sequencial
- Tabelas hash
- Busca binária
- Busca interpolada

### 🔹 Estruturas Hierárquicas
- Árvores binárias
- Árvores binárias de busca (BST)
- Árvores AVL
- Árvores Heap
- Árvores B
- Árvores B+
- Árvores de prefixo (Trie)

### 🔹 Estruturas Avançadas
- Conjuntos disjuntos (Union-Find)
